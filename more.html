Stat Definitions & Methodology

Reference guide for how daily metrics are tracked and calculated in the app:

Stat Meaning & Logic
Items Total individual food & drink records logged for that date.
Meals Distinct count of main meal types logged (Breakfast, Lunch, Dinner). Max 3 per day.
Snacks Total entries categorized as Mid-Morning Snack or Evening Snack.
Beverages Entries with category set to Beverages (coffee, tea, juices, water, etc.).
New Foods Entries marked with "First time trying this" to track dietary variety.
Packaged Foods Entries marked as packaged/processed commercial store-bought products.
First / Last Intake Earliest and latest logged time of intake during that calendar day.

About Daily Intake Tracker

A personal food & drink diary designed for friction-free logging, clean meal timelines, and mindful observation.

Important Notice:
The stats and trends this app shows (item counts, timing, category mix, "new foods" tally) are simple tracking statistics for your own personal awareness — not a medical diagnosis or nutritional assessment.

Install & Cloud Setup

To install this app on your phone or desktop:

  • Android Chrome: Tap browser menu (⋮) → Install app or Add to Home screen.
  • iOS Safari: Tap Share icon → Add to Home Screen.
  • Desktop Chrome / Edge: Click the install icon in the address bar.

Built on static HTML/CSS/JS + Supabase (Postgres + Auth + RLS) + GitHub Pages.
